# Prunus - Personal Pocket Dimensions Mod

Minecraft Forge 1.21.1 mod for personal pocket dimensions.

## Features

- Each player gets a unique pocket world (UUID-based)
- Empty dimension with a spawn block and skylight
- Auto-return when falling into the void
- Keybind for quick enter/exit

## Commands

- `/prunus` or `prunus` — teleport to pocket dimension
- `/malus` or `malus` — return back

## Controls

- `Toggle Pocket Dimension` — keybind **G** by default (Options -> Controls)

## Installation

1. Install Minecraft Forge 1.21.1
2. Copy `.jar` file to `mods` folder
3. Launch Minecraft

## Requirements

- Minecraft 1.21.1
- Forge 52.1.0+
- Java 21
